# Archived LightTable plans

These files are intentionally retained but no longer direct implementation.
They contain useful research, failed approaches, migration context and
acceptance criteria. Current code and tests lead, followed by the active
root-level contracts and trackers listed in `../README.md`.

Archive a document only when a newer contract or implementation has clearly
replaced its authority. Do not archive open product research merely because it
is old, and do not delete archived knowledge during routine cleanup.
