# Generated Vello WebAssembly

The files in this directory are generated by `npm run build:vector-vello-wasm`.
Normal LightTable builds verify their source and output hashes and do not need
Rust, network access or the ignored Vello research checkout.

The generator pins upstream Vello to commit
`3fabef9315914fc2fa32eed12afac8922785396b`, applies the reviewed compatibility
and premultiplied-output patch in Task 303, and runs wasm-bindgen 0.2.126.
