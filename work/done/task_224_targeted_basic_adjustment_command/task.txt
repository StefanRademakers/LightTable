Task 224 - Targeted basic Grade command
========================================

Goal
====

Expose the basic Grade controls as one final typed patch against an explicit
document or layer owner, while preserving the existing local slider preview
path and preventing remote edits from hijacking the open Properties panel.

Scope guard
===========

- This slice covers Temperature, Tint, Exposure, Contrast, Highlights,
  Shadows, Whites, Blacks, Lift, Texture, Clarity, Dehaze, Vibrance and
  Saturation only.
- It does not change any visual adjustment algorithm or default.
- Specialized Photoshop-compatible Adjustment Layers and attached adjustments
  remain outside this command until their distinct schemas are modeled.

Completion evidence
===================

- `grade.setBasic` addresses `{kind: document}` or one stable raster/Grade
  Layer ID and accepts a non-empty partial patch of the 14 scoped controls.
- Slider definitions and command validation consume one shared range map;
  Exposure remains -5..5 and the other basic controls -100..100.
- Canonical target resolution reads document Grade or materializes the target
  layer stack; missing, locked and specialized Adjustment Layers fail closed.
- Background layer mutation publishes canonical document/renderer state while
  leaving an unrelated Properties presentation untouched.
- Pointer/keyboard slider previews remain in the existing local transaction;
  only its successful final commit is observed as one Action step.
- UI-origin, Actions and authenticated MCP routes produce equivalent basic
  Grade values and history for one multi-property document patch.
- The packaged desktop Actions flow records a real Exposure slider edit,
  binds its nested target to `$step6.layerId`, undoes seven mixed operations
  and replays them successfully.
- Focused adjustment/command run: 111 test files, 1,168 tests passed.
- Workspace typecheck, command contract/drift, application boundary, UI
  boundary and packaged desktop build passed.
