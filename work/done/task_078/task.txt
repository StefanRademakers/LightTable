# Task 078 — remote LightTable MCP v1

Status: completed 2026-08-06.

Implemented a transport-neutral MCP vertical slice over the existing semantic
LightTable application command service. The remote Node service provides
Streamable HTTP, OAuth authorization-code + PKCE, protected-resource metadata,
dynamic client registration, read/edit scopes, rotating refresh tokens and a
bounded pairing flow. The desktop side is a bearer-authenticated loopback-only
bridge; no editor model, renderer or undo implementation was duplicated.

Implemented compact document/layer/effect/capability queries, typed commands,
bounded gestures, safe public image import, real GPU PNG previews and opaque
native/PNG/PSD artifacts. Semantic edits and committed gestures now advance
the canonical document revision synchronously, so stale-write preconditions
are meaningful through MCP.

The deployment and security model, Hetzner/systemd/reverse-tunnel example,
current tool inventory, honest limitations and next semantic slices are in
`architecture/integrations/LIGHTTABLE_MCP_V1.md`.

The bundled OAuth store is deliberately single-process/in-memory for the
private v1 trial. A public multi-user service still requires an external
durable identity/authorization layer, centralized throttling, CSRF/session
hardening, audit retention and tenant isolation.
