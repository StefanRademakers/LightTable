  identity changes and reports their conservative GPU size to the existing
  512 MiB/100-entry history budget. Previously these commands reported zero

  at most the latest 100 entries while Copy all retains the full bounded log,
  preventing an inactive panel from growing its DOM for repeated comparison
  samples.

Command: `npm run stress:desktop -- --iterations 10 --file <path>`; repeat
`--file` for multiple documents. The script defaults to the three verified
fixtures above and never saves.
