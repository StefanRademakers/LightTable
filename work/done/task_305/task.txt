LightTable Vello path decomposition and render-island architecture

Status: complete and archived. The production hybrid renderer and retained
island architecture are active; REPORT.md preserves the measured evolution and
the one unavailable Chromium GPU-timestamp capability as a negative result.

Goal
Profile the complete Vello update path without attributing LightTable integration
cost to Vello itself. Remove avoidable unchanged-scene work, establish correct
visibility retention, diagnose the first-close spike, and specify the production
render-island architecture without changing canonical document editability.

Acceptance checklist
[x] Separate canonical projection, JS PaintScene construction, validation,
    JSON serialization, JS/WASM transfer estimate, Rust deserialization,
    fragment encoding, scene synchronization, Vello preparation and CPU submit.
[x] Measure cache/dependency work, surface lifecycle and final LT compositing.
[x] Ensure unchanged scenes never enter PaintScene compilation or WASM.
[x] Keep hidden canonical vector resources warm; release only deleted resources.
[x] Classify the 264 encode visits in the representative layered SVG workload.
[x] Identify the first-close 1.3 s observation by exact blocking location.
[x] Determine minimal compositing boundaries for the representative fixture.
[x] Assess JSON, binary, typed arrays, shared memory and retained Rust mutations.
[x] Preserve normal-build behavior; GPU timestamp instrumentation is diagnostic.
[x] Implement the pure render-island planner and diagnostic projection.
[x] Add deterministic retained runtime-ID reconciliation for island split/merge.
[x] Integrate island-owned retained surfaces and cross-layer Rust scenes.
    The representative layered fixture is 17 -> 5 resources. Unsupported
    compositing remains on the established per-layer fallback; broader exact
    pixel parity is deliberately still a renderer release gate.
[x] Implement bounded active/warm/cold/evicted resource policy, including
    coherent rehydration after the bounded Rust retained-scene cache evicts a
    source that still has a canonical JS projection.
[x] Stress packaged layered and 26k-path SVG workloads across repeated layer,
    zoom, pan and panel actions without crashes or suspicious resource growth.
[x] Determine whether exclusive GPU timestamps are available through the
    packaged Chromium path. The diagnostic build reported
    `actualGpuTimingAvailable: false`; queue-completion wall time remains the
    honest supported metric until a separate native/capture path is introduced.
