Task 216 - Semantic gesture commit and automation performance

Goal
====

Ensure sliders, transforms, color drags, paint and selection interactions stay
responsive while Actions and MCP observe one meaningful committed operation
instead of raw UI-event storms.

Parent goal
===========

[`architecture/goals/AGENT_NATIVE_CREATIVE_RUNTIME_TARGET.md`](../../../architecture/goals/AGENT_NATIVE_CREATIVE_RUNTIME_TARGET.md)

Required work
=============

- Inventory high-frequency interactions and their current preview/history
  owners.
- Standardize begin/update/finish/cancel gesture semantics and execution origin.
- Keep preview updates transient; publish and record one final semantic result.
- Coalesce keyboard repeats and numeric/slider edits without losing final value.
- Bound sample count, payload bytes, duration and concurrent sessions.
- Define disconnect, pointer-cancel, document-close and stale-revision behavior.
- Prevent playback/MCP updates from recursively recording or creating history
  spam.
- Instrument command count, render submissions, history entries, recorder bytes
  and commit latency for representative gestures.

Representative proof
====================

- Adjustment slider drag with many preview values and one recorded commit.
- Layer transform drag with cancel and commit paths.
- Brush or selection stroke with bounded samples and one undo operation.
- UI responsiveness and dirty-only rendering remain at least as good as before
  the semantic route.

Definition of done
==================

- Representative gestures record/replay one semantic step where replay is
  meaningful.
- Preview remains responsive and does not wait on MCP serialization.
- History and renderer telemetry prove bounded publication.
- Cancel/disconnect leaves the document in a defined recoverable state.

Non-goals
=========

- Sending every pointer sample through the ordinary command catalog.
- Treating a synthetic timing number as product responsiveness proof.

Current evidence (2026-08-20)
=============================

- Coalesced pointer input reaches Paint and Warp through one `moveMany` call
  per browser event; renderer work remains frame-scheduled.
- A 2,049-sample recorded Brush stroke is protected by a regression contract:
  one scheduled renderer batch, one history entry and one semantic commit.
- A 2,048-sample `tool.commitGesture` request records and replays as one bounded
  Action/MCP operation; it does not require remote pointer simulation.
- A 2,048-update affine transform remains preview-only until one final document
  result; the recorder observes only that committed result.
- Oversized recorder payloads fail closed while live painting continues.
- Packaged Actions and Brush UX flows passed after integration.
- A real packaged Exposure slider gesture records one final `grade.setBasic`
  step and replays it; pointer/keyboard preview values never enter command
  transport individually.
- Live automation gestures now have a 30-second renewable lease. Timeout,
  document close, command-service disposal and Agent Access stop all cancel
  through the existing editor gesture owner; a packaged stop/restart flow
  proves a subsequent selection gesture is accepted without restarting the app.
- Native live-shape drags retain their existing local provisional document path.
  A single callback publishes `vector.create` only after successful commit; a
  packaged 16-move Rectangle drag records one step and replays one editable shape.
- A packaged three-anchor Pen session keeps anchor/handle/rubber-band previews
  local and records one `vector.create` only after commit. Resuming an existing
  path similarly records one final `vector.update`.
- A twelve-sample packaged Direct Selection drag records one final path update.
  Cancel, no-op click and marquee-only selection produce no semantic mutation.
- Packaged Gradient Fill drags publish only their final native create/update;
  intermediate axis samples, cancellation and color-stop endpoint clicks remain local.
- Packaged Warp recorded Push and held Twirl as two final semantic recipes and
  two history entries while pointer/hold previews remained on the frame-coalesced
  local controller. The final representative run retained 21 samples in about 3.6 KB
  and reported 32 submitted frames; these measurements are not a latency score.
- A packaged 18-move raster-gradient drag publishes no command before pointer-up
  and one final paint/history entry afterward; Actions/MCP never receive moves.
- A packaged 24-move Dodge gesture over non-neutral pixels likewise publishes
  one final tone stroke only after GPU/history success; the paint hot path and
  frame scheduler are unchanged.
- A packaged Clone gesture keeps source selection and 24 pointer moves local,
  then publishes one bounded stroke only after pointer-up GPU/history commit.
  Source snapshotting stays at stroke begin and no pixel data enters transport.
- A focused packaged regression commits Fill, raster Gradient and a 24-move
  Brush stroke, then proves an immediately selected different layer remains
  canonical after React publication and idle.
- Magic Wand remains a single local click plus asynchronous GPU work. Its
  semantic command publishes only after the current result enters selection
  history; no mask or polling samples enter command transport.

- The packaged Actions smoke now captures release-to-command/history latency,
  release-to-next-frame latency, submitted frames, recorder bytes and stage
  encode counters without putting pointer samples on the diagnostic boundary.
  Before release it asserts that canonical revision, history and Actions remain unchanged.
- In three representative packaged runs, a 24-move Brush stroke produced 25 local
  preview submissions and one post-commit submission, one Action, one undo entry
  and a 1,834-byte recorder delta. Observed release-to-command/history time was
  18.53-19.57 ms and release-to-next-frame time was 21.03-22.53 ms.
- In those runs, an 18-move Exposure drag produced 18-20 local preview
  submissions and one post-commit submission, one Action, one undo entry and a
  240-byte recorder delta. Observed times were 14.82-22.46 ms and 25.79-43.39 ms
  respectively. These machine/run-specific durations are diagnostic evidence,
  not product thresholds or a synthetic responsiveness score.
- The reproducible report is written by `npm run smoke:desktop:actions` to
  `tmp/actions-panel-smoke/semantic-gesture-runtime.json`.

Completion
==========

All required representative gesture, cancellation, bounded-publication and
packaged runtime evidence is present. Interactive pointer/paint previews remain
local and frame-scheduled; Actions and MCP receive only final semantic results.
