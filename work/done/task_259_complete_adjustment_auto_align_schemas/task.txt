Evidence
========

- The adjustment schema derives its public enum from the currently visible
  product catalog and rejects hidden `vibrance`, invalid local kinds,
  contradictory targets and UI/private fields. Results distinguish local,
  attached and standalone stable IDs.
- Auto Align input contains only two stable layer IDs. Its task boundary now
  converts the internal estimator result into `changed`, `referenceLayerId` and
  `targetLayerId` before Actions completion; model, confidence, diagnostics,
  preview reuse and matrices remain application-private.
- Contract tests cover every placement and private-result rejection. Application
  tests cover validation, recording, task completion, cancellation and replay.
  External MCP discovers both complete schemas, rejects private/contradictory
  input, creates all three adjustment placements and applies real Auto Align.
- Verification passed: full workspace typecheck and tests (485 app files / 2790
  app tests), command-contract, source-structure, architecture, boundary and UI
  audits, desktop packaging, external MCP smoke, packaged Actions smoke,
  packaged UI/Actions/MCP route equivalence and `git diff --check`.
