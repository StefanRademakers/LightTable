# Task 098 — semantic vector, gradient and Layer Style commands (P1/P3)

Priority: P1 foundation for P3. Depends on Tasks 092 and 096. Expected effort:
8–12 focused hours.

## Objective

Expose canonical shapes, paths, fills, strokes, gradients and Layer Styles to
UI/automation/MCP without duplicating geometry or effect models.

## Required work

- Typed create/update commands for primitives and bounded path commands,
  transform, fill/no-fill, stroke/no-stroke, gradient asset/stops and opacity.
- Add/update/remove/reorder/toggle supported Layer Style effects with validated
  settings and effect IDs.
- Reuse shared gradient assets and property controls; bound points/stops/effects
  and reject non-finite/out-of-policy payloads.
- Expected revision and capability reporting on every mutation.
- One semantic mutation/transaction has deterministic undo and derived-cache
  invalidation; no direct GPU or React state access.

## UI exposure

Route Shape/Gradient property bars and Layer Style panel through the same
commands where practical, preserving high-frequency preview controllers.

## Verification and completion

- Create/edit/undo/save/reopen/PSD for rectangle, ellipse, star, line, compound
  path, solid/gradient fill, strokes and each supported effect.
- MCP-generated and UI-generated canonical snapshots/pixels must match.
- Bounds, malformed-input, performance and cache invalidation tests.
- Run vector/gradient/effects/MCP/parity gates and builds; docs, commit, move.

## Completion (2026-08-06)

- Added validated semantic commands for primitive/live shapes, bounded compound
  paths, transforms, fill/no-fill, stroke/no-stroke and solid/gradient paints.
- Added validated Layer Style add/update/remove/reorder/toggle operations with
  stable effect IDs for all ten supported effects and deterministic history.
- Reused the canonical vector, gradient and Layer Style models throughout the
  UI, command service and MCP; high-frequency property previews remain local.
- Added bounded full-fidelity vector queries plus focused MCP create/edit/style
  tools without a second geometry, paint, render or effects representation.
- Packaged Electron measurements: vector create 26.95 ms and effect add
  16.65 ms. Native and PSD reopen preserve editable vector/style semantics.
- Verification passed: full workspace tests (321 app files / 1,742 app tests),
  web build, packaged desktop verification, semantic command-driver smoke,
  boundary and third-party gates; focused vector, gradient, effects, PSD and MCP
  suites also passed.
