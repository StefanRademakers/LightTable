# Task 089 — supported-hardware performance and soak release gate (P0)

Priority: P0. Depends on current complete-app gate. Expected effort: 6–12 hours.

## Objective

Define an honest minimum hardware floor and a multi-hour-equivalent automated
soak that catches crashes, leaks, background work and interaction regressions.

## Required work

- Record CPU/RAM/GPU/driver/display-scale/OS/build validity metadata.
- Add scenario loops for ordinary image, TextTest, shapes, PDF and EHS-396:
  open, pan/zoom, layers, selection, paint, transform, text caret/edit, styles,
  save/export, close and reopen.
- Separate input-to-submit, GPU completion, final settle, first useful frame,
  heap stable tail, owned GPU bytes, DOM/listeners and background submissions.
- Support duration/iteration profiles so CI runs a bounded sample and an
  unattended local run covers at least twelve hours.
- Detect zero-action samples and early/deferred-preview screenshots as invalid.
- Establish provisional Windows discrete/integrated targets; Mac and other GPU
  claims remain unavailable until measured on physical hardware.

## UI exposure

No normal-user panel. Feed the bounded diagnostic summary from Task 087 and
keep detailed artifacts under `tmp/quality-audit`.

## Verification and completion

- Run the longest locally practical soak and document extrapolation honestly.
- Zero runtime/page/WebGPU errors, orphan processes and monotonic stable-tail
  growth; ordinary direct manipulation target remains 16.7 ms.
- Add the gate to the appropriate desktop/full profile without slowing quick.
- Update performance/reliability baselines, commit and move.

## Completion evidence (2026-08-06)

- Added a production release-soak orchestrator with bounded `ci`, one-hour
  `local` and genuine 720-minute `overnight` profiles plus explicit duration,
  cycle, iteration and output overrides. Desktop/full quality runs the bounded
  profile without slowing quick.
- Every cycle drives an ordinary PNG, TextTest, shapes, PDF and EHS-396 through
  open/ready, layer and panel work, pan/zoom, selection, paint, transform, text
  create/caret/edit, Layer Style input, save/export, PSD semantic roundtrip,
  process close and reopen. Zero actions, missing first-frame samples, early or
  empty screenshots and stopped/non-positive-GPU final samples invalidate the
  result.
- Reports separate first useful frame, canvas final settle, Type Tool
  input-to-submit and queue completion, forced-GC heap, owned GPU bytes, DOM,
  listeners, mutation/history residency, unchanged background submissions and
  orphan processes. The Task 087 diagnostic bundle contributes selected GPU,
  build and privacy-validity data without recomposition/readback.
- Refined native keyboard isolation discovered by the canvas gate: Layers now
  retains document shortcuts such as mask `Ctrl+I` while dialogs/menus/flyouts
  remain exclusive. The mask lifecycle test now waits for the active channel
  and uses a stable raster owner. PSD/screenshot automation follows the new
  menubar `menuitem` semantics and dismisses compatibility dialogs correctly.
- Longest practical local evidence: three independent production cycles, four
  document iterations each, 255.4 seconds on Windows 11 build 26200 / Core
  Ultra 9 285K / 64 GiB / selected NVIDIA Blackwell RTX 5090. All 15 document
  runs and specialized tests passed with zero page/runtime/WebGPU errors, zero
  new orphan processes and zero submitted frames in every 750 ms unchanged
  window.
- Ordinary first useful frame was 758-764 ms and EHS-396 1714-1773 ms. The
  warm non-mutating canvas tail measured +0 owned GPU bytes, +0 DOM, +0
  listeners and about +0.53 MiB heap. Layer Style published about 16.6 Hz with
  no long task. Type remains a quantified parity gap: 32.9-65.3 ms to submit
  and 67.7-117.6 ms to GPU completion across the three cycles.
- The run is explicitly not twelve-hour, integrated-GPU or macOS evidence.
  Candidate floors, provisional targets, unavailable claims and commands are
  recorded in `architecture/SUPPORTED_HARDWARE_AND_SOAK_GATE.md`.
- The final quick profile passed boundaries, source/docs audits, all workspace
  typechecks, the soak policy tests, 317 app test files / 1692 tests, all other
  workspace tests and the production web build. The production package,
  canvas gate, three-cycle soak and bounded CI soak passed independently.
