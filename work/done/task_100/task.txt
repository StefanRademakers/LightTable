# Task 100 — unified Layers tree and property-control language (P2)

Priority: P2. Depends on P1 canonical properties. Expected effort: 10–16 hours.

## Objective

Make Layers, Grade, Lens Fx, Text, shapes and Layer Styles feel like one product
without hiding compatibility semantics or introducing custom controls.

## Required work

- Inventory every row, thumbnail, indent, disclosure, visibility, selection,
  active target, mask and effect state; define one tokenized Layers geometry.
- Square bounded thumbnail cells contain evaluated aspect/transforms; content
  never changes row width or escapes during scaling.
- Distinguish active layer/target, multi-selected rows and hover using accessible
  tokens; only present effects/masks appear in the tree.
- Inventory dropdowns, numbers/spinners, checkboxes, switches, sliders, color/
  gradient widgets, angle controls and Advanced disclosures.
- Consolidate shared primitives and spacing first; remove feature-local visual
  lookalikes only after behavior parity tests.
- Preserve Photoshop-compatible shortcuts/semantics while using the simpler
  Pixelmator-like disclosure policy: common controls first, compatibility under
  Advanced.

## UI exposure

Apply incrementally to Layers and Drop Shadow first, then Text/Shape/Gradient
and remaining effects/panels. No new design language or modal property editor.

## Verification and completion

- Screenshot matrix at supported panel widths, scaling, long names, nesting,
  masks/effects and 100/200% OS scale.
- Keyboard/focus/contrast plus large-stack scrolling/performance.
- Existing tool/property/effect semantic tests remain unchanged and green.
- Run UI smokes, quick/desktop builds, update design-system docs, commit coherent
  component slices and move after full inventory reconciliation.

## Completion (2026-08-06)

- Defined one tested Layers geometry contract for row spacing, nesting,
  clipping, bounded 42 px square thumbnail slots and the fixed status column;
  transformed evaluated previews remain aspect-contained and cannot resize or
  escape the row.
- Added distinct tokenized hover, multi-selection, active-target and keyboard
  focus presentation. Only canonical masks and present effects are rendered;
  long names and status badges stay clipped inside their assigned slots.
- Consolidated Layer Styles onto shared panel select, checkbox, color, slider,
  angle and Advanced disclosure primitives. Grade/Lens Fx continue to share
  slider/switch primitives and Text/Shape/Gradient share ToolOptionControls.
- Added off-screen row paint containment. The 42-row nested EHS-396 stack
  measured 16.9–17.1 ms p95 across compact/wide windows and 100/200% device
  scale after settling, down from the initial 167.8 ms failing audit.
- Added the repeatable `audit:desktop:panel-language` screenshot, geometry,
  focus, overflow and scroll-performance matrix. All four cases and the full
  keyboard/accessibility journey passed without page errors or unnamed
  controls; evidence is generated under `tmp/panel-language-audit/`.
- Verification passed: 326 app test files / 1,759 tests, app typecheck, web
  production build, packaged Electron boundary check, panel matrix and desktop
  accessibility smoke.
