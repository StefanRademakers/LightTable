Task 240 - Semantic Path Text creation
======================================

Goal
====

Route native Path Text creation through the existing text.create command so UI,
Actions and reviewed Agent/MCP callers create the same editable path-bound text.

Checklist
=========

- [x] Extend text.create with explicit native path layer, element and contour references.
- [x] Include bounded start offset, side, upright and direction settings without transport DOM/vector objects.
- [x] Make the real Path Text UI use text.create and retain its current font/style/editing behavior.
- [x] Reject missing/non-path/ambiguous targets and invalid layout settings without partial layers.
- [x] Preserve path dependency, rendering, transform and undo behavior.
- [x] Prove packaged UI/Actions creation and replay plus Agent Access and external MCP creation/query.
- [x] Run full gates, update parent work items, complete and commit.

Scope guard
===========

- The command references existing native vector geometry; it never embeds or
  duplicates the path.
- Path authoring/editing remains in vector commands.
- Photoshop path-text visual parity is not claimed by route equivalence.

Completion contract
===================

One normal Path Text click on an explicitly selected native contour records one
text.create Action. Replay and direct callers create editable flow text bound to
the requested contour through the same semantic text executor.

Evidence
========

- The real Path Text toolbar flow records one `text.create` after native path
  selection. Packaged undo/replay recreates editable path-bound flow text using
  stable result bindings from the recorded `vector.create` step.
- Agent Access and the external MCP bridge create a native vector contour,
  create Path Text against it and query back exact layer/element/subpath,
  start-offset, side, upright and direction values.
- Contract tests reject missing and malformed path settings. Executor regression
  coverage proves a missing contour cannot create, rename or publish history for
  the previously active vector layer.
- Full verification passes: 462 app test files / 2,593 tests, 17 MCP tests, all
  workspace typechecks, packaging, boundary, source-structure, architecture-docs
  and command-contract checks, plus broad packaged Actions regression.
- This proves route and editable-state equivalence; Photoshop visual parity is
  intentionally not claimed.
