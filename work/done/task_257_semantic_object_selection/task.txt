Task 257 - Semantic Select Subject vertical

Goal
====

Expose Select Subject as one stable, reproducible and cancellable selection
capability shared by normal UI, Actions and reviewed MCP execution. The current
segmentation model, point/box prompts, hover, preview masks, refinement pipeline,
model tensors and raster bytes remain replaceable desktop implementation details.

=============

Definition of done
==================

- UI, Actions and MCP reuse the same Select Subject controller and raster-selection
  history owner.
- One UI operation produces one selection history commit and one semantic Action.
- Model load/inference is cancellable and stale completion cannot mutate state.
- No model/backend/candidate identity, refinement setting, point/box prompt,
  pointer stream, hover preview, tensor, PNG or raster mask crosses the command boundary.
- Packaged Object Selection and external MCP evidence pass without regressing
  interactive paint, warp or selection performance.
