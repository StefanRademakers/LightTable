Task 247 - Explicit raster and mask invert

Goal
====

Expose Layer > Invert Colors as one explicit raster/mask GPU commit shared by
UI, Actions and Agent/MCP, without duplicating pixel operations or weakening
the central command-service structure gate.

Evidence
========

- `raster.invert` accepts exactly a stable layer ID and `pixels`/`mask` channel;
  missing layers, non-raster pixel targets, absent masks and locked targets fail
  before touching the renderer.
- A shared version-1 input/result schema now exposes the same exact target and
  channel boundary to Actions/MCP discovery; expanded channel values fail
  before the GPU owner.
- The pre-existing layer document owner now accepts an explicit ID but retains
  its begin/invert/finish GPU transaction, pixel-history snapshot, revision
  update, undo/redo and error handling.
- Layer menu and keyboard invocation resolve active target once and dispatch the
  same command used by Actions and MCP.
- The packaged MCP smoke inverts the explicit raster twice, proving two revision
  increases while restoring the image before later rendered assertions.
- Command capability projection moved out of the central service into a pure
  read-only module; source structure passes without raising its reviewed growth
  baseline.
- Coverage now reports 18 genuine menu gaps.
- Verification passed: full workspace tests (469 app files / 2646 app tests),
  typecheck, packaged desktop boundary, external MCP smoke, source structure
  (885 handwritten files), architecture docs, command coverage and UI boundary.
