Evidence
========

- `tool.commitGesture` has three closed variants. Brush covers all current
  presets/settings plus Tone and document-relative Clone/Healing recipes;
  Selection Rectangle and Layer Translate accept only their semantic fields.
- `warp.applyStroke` retains the editable layer-source samples, timing, mode and
  immutable settings, returning only stable layer/stroke IDs and sample count.
- Contract tests reject pointer IDs/types, runtime textures, preview/debug state,
  incompatible erase/operator combinations and out-of-range recipes.
- No live interaction source changed. Packaged Actions still recorded one
  1,834-byte operation for 25 local Brush updates and one operation per Warp
  recipe. Preview submissions remained local and frame-scheduled.
- External MCP discovered both complete schemas, rejected private state before
  the bridge, executed real Tone/Healing/Warp recipes and queried editable Warp.
- Full typecheck and tests passed (485 app files / 2790 app tests), as did
  contract, source, architecture, boundary and UI audits, desktop packaging,
  Actions, MCP and two consecutive final route-equivalence runs.
