Task 218 - Bounded agent observation, preview and events

Goal
====

Give an agent enough bounded structural and visual feedback to inspect a
document, connect a preview to an exact revision, observe changes and make one
measured correction without polling or transferring full document payloads.

Parent goal
===========

[`architecture/goals/AGENT_NATIVE_CREATIVE_RUNTIME_TARGET.md`](../../../architecture/goals/AGENT_NATIVE_CREATIVE_RUNTIME_TARGET.md)

Required work
=============

- Define bounded document summary, scene graph and targeted object queries.
- Include explicit coordinate spaces, bounds, type, visibility, relevant
  properties, resource availability and truncation/cursor metadata.
- Add revision-bound whole-document preview and evaluate bounded region/layer
  previews without moving the user's viewport.
- Reuse unchanged preview artifacts and avoid repeated full-resolution renders.
- Extend reconnect-safe events for document, selection, layer, render, history
  and task publication where they materially reduce polling.
- Enforce read permissions, artifact limits, privacy redaction and resource
  lifetime/release.
- Keep visual comparison optional and diagnostic; it may not become another
  misleading universal parity score.

Current evidence (2026-08-20)
=============================

- `grade.queryBasic` provides a bounded 14-number projection for an explicit
  document or raster/Grade Layer target; it does not expose nested Grade state.
- Locked targets remain inspectable while the corresponding mutation command
  remains blocked.
- A packaged authenticated Agent Access flow sets document Grade, reads the
  canonical values back and proves the query does not change revision, dirty
  state or history.
- `document.preview` now produces cached, bounded 64-1024 px GPU artifacts tied
  to an exact canonical revision without moving the viewport. Stale and
  mid-render document changes fail closed, and released artifacts regenerate.
- `layer.list` now returns compact revision-bound cursor pages (default 128,
  maximum 256). A cursor from another document or revision fails closed, and
  list rows no longer inline vector-element geometry.
- `layer.preview` now returns bounded isolated raster-layer pixels or a raster
  mask through the mounted GPU layer renderer, including exact source-to-output
  mapping metadata and without moving the viewport.
- MCP `lighttable_region_preview` now returns an exact document-pixel crop of the final
  composite through the same GPU crop/encode owner as Copy Merged, without
  creating a selection or changing the viewport.
- `layer.query` resolves an explicit or active layer and returns a compact
  type-dispatched raster/group/adjustment/vector/text content summary plus the
  targeted queries and previews that are actually available.
- Whole-document and layer MCP previews accept `knownArtifactId`; an unchanged
  artifact returns metadata without retransferring its Base64 image payload.
- Preview `maxEdge` is explicit (64-1024). PNG remains lossless; WebP exposes
  real quality control from 0.1-1, and format/quality participate in cache identity.
- Packaged external MCP now proves inspect revision N -> preview N -> semantic
  edits -> preview N+1 through the real renderer and artifact tunnel.
- `event.query` now exposes bounded reconnect-safe document, revision, active
  layer, selection, history, task and renderer-state publications. Cursor gaps
  are explicit and force canonical re-query rather than silently missing work.
- `event.wait` and MCP `lighttable_wait_for_events` now hold one read-only call
  for at most 10 seconds and return immediately for queued events or a cursor
  gap. The application owns at most 64 concurrent waiters and releases them on
  timeout or service disposal; the transport retains its separate 64-request /
  15-second boundary.
- The packaged MCP flow records a cursor before editing, observes its exact
  final revision/history publication and then requests preview N+1.
- The packaged outbound TLS/WSS device route starts a wait and a concurrent
  native edit. It wakes on `active-layer-changed`, then one cursor drain returns
  `history-changed` plus the edit's exact `document-revision-changed`. The local
  MCP end-to-end route proves the same sequence. Blind interval polling is no
  longer required; unsolicited server push is not claimed.
- Targeted text, vector, effects, Warp and basic Grade queries exist.
  `adjustment.query` now adds bounded module-registry-backed parameters for
  document Grade/Lens Fx, raster/Adjustment Layers and attached adjustments;
  every current adjustment catalog presentation is covered without exposing
  LUT bytes or unknown renderer settings. Evidence is in completed
  [`Task 255`](../../done/task_255_complete_adjustment_observation_schemas_task/task.txt).

Representative proof
====================

An MCP client inspects structure and preview at revision N, performs one native
edit with an expected revision, waits for render publication, requests the new
preview at revision N+1 and identifies the changed object/region.

Definition of done
==================

- Observation payloads remain bounded on large/deep documents.
- Preview artifacts identify exact document/render context and are released.
- Events avoid blind polling and survive reconnect through cursors.
- The proof uses the real renderer and remote bridge.

Non-goals
=========

- Returning the complete serialized document by default.
- Disturbing the active viewport to create an agent preview.
- Autonomous reference decomposition in this task.

Completion result (2026-08-20)
==============================

The bounded observation loop passes through the packaged renderer and the real
outbound Agent Access/MCP device route. An agent can inspect revision-bound
structure, request size/format/quality-controlled whole, region and layer
previews, reuse or release artifacts, wait without interval polling, drain the
reconnect cursor, execute a native edit and request the exact newer render.
Payload, artifact, wait, timeout, concurrency, cursor-gap, stale-revision and
permission boundaries remain explicit. This completes the observation task;
it does not complete autonomous visual judgment, reference reconstruction or
the parked remote ephemeral-preview transport experiment.
