  semantics.

  ungrouped and deleted through immutable document/history paths.
- Structural moves preserve world transforms and stable source layer IDs.
- Raster/vector-only destructive commands reject text explicitly.
- Text uses a bounded diagnostic projection in the existing WebGPU vector
  compositor and cannot hide an ordinary raster below it.
- Layers exposes a text icon and source-kind diagnostic only.
- Native save rejects text explicitly until Slice 04 supplies its complete
  versioned persistence contract.
