RESOLVED 2026-09-11

Root cause: pointer-up checkpoints remained newer than canonical document state,
while a following semantic command could enter its handler without retiring the
transform owner. The command service now serializes revision admission,
interaction settlement and dispatch per document. The mounted owner publishes
the latest selection/transform state before the next semantic command.

Packaged proof: copy/paste selection -> selected-pixel transform -> mouse-up
without Enter -> Drop Shadow produces two ordered history entries, retains the
transformed pixels, exposes rasterize, and restores exact pixels through two
undo/two redo operations.
