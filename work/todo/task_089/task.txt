# Task 089 — supported-hardware performance and soak release gate (P0)

Priority: P0. Depends on current complete-app gate. Expected effort: 6–12 hours.

## Objective

Define an honest minimum hardware floor and a multi-hour-equivalent automated
soak that catches crashes, leaks, background work and interaction regressions.

## Required work

- Record CPU/RAM/GPU/driver/display-scale/OS/build validity metadata.
- Add scenario loops for ordinary image, TextTest, shapes, PDF and EHS-396:
  open, pan/zoom, layers, selection, paint, transform, text caret/edit, styles,
  save/export, close and reopen.
- Separate input-to-submit, GPU completion, final settle, first useful frame,
  heap stable tail, owned GPU bytes, DOM/listeners and background submissions.
- Support duration/iteration profiles so CI runs a bounded sample and an
  unattended local run covers at least twelve hours.
- Detect zero-action samples and early/deferred-preview screenshots as invalid.
- Establish provisional Windows discrete/integrated targets; Mac and other GPU
  claims remain unavailable until measured on physical hardware.

## UI exposure

No normal-user panel. Feed the bounded diagnostic summary from Task 087 and
keep detailed artifacts under `tmp/quality-audit`.

## Verification and completion

- Run the longest locally practical soak and document extrapolation honestly.
- Zero runtime/page/WebGPU errors, orphan processes and monotonic stable-tail
  growth; ordinary direct manipulation target remains 16.7 ms.
- Add the gate to the appropriate desktop/full profile without slowing quick.
- Update performance/reliability baselines, commit and move.
