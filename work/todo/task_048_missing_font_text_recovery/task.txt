# Task 048 - Missing-font text recovery

Status: in progress

Native LightTable, PSD, PDF and AI text with unavailable fonts must remain
semantically recoverable. A retained bounded raster preview provides visual
fidelity until the user chooses a replacement; it must not become the only
representation of the layer.

## Desired behavior

- [x] Preserve supported text semantics, runs, layout, transform, path and the
  original raster preview when one or more referenced fonts are unavailable.
- [x] Give the canonical text-layer contract an optional derived preview-cache
  asset reference plus source/font fingerprints; adapters must map into this
  shared contract instead of inventing format-specific fallback layers.
- [x] Persist that bounded preview, cache version and fingerprints in the native
  LightTable format so the same behavior survives save/reopen on another
  machine without the original font.
- [x] Invalidate/rebuild the preview when authoritative text, layout, transform,
  rendering version or resolved font fingerprints change; keep it reusable and
  evictable while nothing relevant changed.
- [x] Render the retained preview while unresolved and show the existing
  missing/substituted-font status on the text layer.
- [x] On the first edit attempt, use existing dialog/components/CSS to offer
  `Cancel`, `Replace` and `Manage` instead of silently rasterizing or failing.
- [x] `Replace` chooses an available bundled/document/system font, realizes the
  preserved text through the normal WASM + WebGPU text pipeline and leaves the
  layer fully editable.
- [x] `Manage` opens the existing document compatibility dialog with missing
  fonts grouped by requested face, an existing font selector and one Replace
  all action for every affected editable layer.
- [x] Keep the retained source preview as a non-authoritative fidelity reference
  after replacement; do not composite it once native text is authoritative.
- [x] Record a single-layer or document-wide replacement as one undoable
  canonical document snapshot; the selected asset reference and fingerprint
  use the existing native persistence and text-export paths.

## Gates

- [x] The EHS template corpus exposes unavailable Photoshop fonts as text layers
  with a preview rather than raster-only layers where semantics are supported.
- [ ] A native LightTable file created with a temporarily available font reopens
  visually from its cached preview when that font is absent, then becomes native
  editable text after Replace without losing its runs/layout/path.
- [x] Cancel changes nothing; Replace produces editable text; Manage resolves
  repeated missing fonts across the document without changing runs that use a
  different available face.
- [ ] Mixed available/missing runs, paragraph text, point text, rotations and
  text-on-path have focused tests.
- [ ] Web remains functional with bundled/document fonts; desktop system fonts
  integrate through Task 046 without a second rendering path.
