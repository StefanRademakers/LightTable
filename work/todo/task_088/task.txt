# Task 088 — accessibility, keyboard and focus release audit (P0)

Priority: P0. Dependencies: none. Expected effort: 6–10 focused hours.

## Objective

Make core open-edit-save workflows keyboard-operable and screen-reader legible
without breaking Photoshop-compatible shortcuts or canvas performance.

## Required work

- Inventory menus, toolbar/flyouts, options bar, dock tabs, Layers, Grade,
  Lens Fx, Text, Layer Style, dialogs, start page and error/recovery surfaces.
- Establish semantic roles, accessible names, focus order, visible focus,
  disabled explanations and escape/return behavior using existing components.
- Preserve tool shortcuts outside text editing; prevent native Electron menu
  focus and hidden popovers from stealing keys.
- Add reduced-motion handling for nonessential UI/overlay animation and verify
  contrast at supported themes/states.
- Build a declarative keyboard journey and accessibility smoke that grows from
  current registry/panel/menu inventory.

## UI exposure

Do not redesign visuals. Repair shared primitives first so all consumers gain
the same focus, label and keyboard behavior.

## Verification and completion

- Keyboard-only: start page → open → select/edit layer → undo → save/export.
- Automated role/name/focus tests plus manual high-contrast/scale inspection.
- Verify Ctrl/Cmd parity, Type Tool exceptions and flyout/menu navigation.
- No React/pointer hot-path regression; run quick and packaged smoke.
- Record remaining OS/screen-reader matrix explicitly, commit and move.
