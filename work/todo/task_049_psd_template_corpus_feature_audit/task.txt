  masks, blend mode, opacity, fill opacity, styles, adjustment descriptors,
  text/font state, vector data and smart-object data where present.

- [ ] For suspect layers, capture both a solo render and an in-context render;

- [x] Group recurring gaps into candidate implementation tasks and rank them by
  affected documents, visual impact and architectural dependency.
- [x] Review the completed feature matrix before implementing candidates.
  Result: the user explicitly approved the inventory-first policy and the

## Canonical/native-format requirements to verify

- [x] Verify layer-local raster/vector bounds outside the canvas. Result:
  runtime import preserves tight translated surfaces, including 63 off-canvas
  and 13 canvas-oversized layers.
- [x] Verify native save/reopen of local bounds and transforms. Result: failed;
  manifest v3 omits raster dimensions/offsets and reassigns document dimensions.
- [x] Verify semantic/editable native representation. Result: groups, mapped
  adjustments and supported vectors are semantic; all 81 corpus text layers
  and 57 smart objects currently use raster layers with preserved descriptors.
- [x] Verify unsupported-feature retention. Result: layer-local previews and
  descriptors cover text/vector/smart-object cases, but embedded smart-object
  content and unsupported adjustment-scope previews are missing.
- [x] Layer-tree thumbnails use consistent square cells with contained aspect
  ratios, while row sizing remains independent of source layer dimensions.
  Result: the shared 40 x 40 thumbnail cell contains source aspect ratio, and
  semantic affine transforms are applied by the GPU thumbnail export. A clean
  packaged capture of `D:\TextTest.psd` verifies the 90-degree text thumbnail
  orientation against the canvas with zero page errors.

## Feature implementation policy

The audit itself is read-only. Each approved feature or independent defect is
implemented with focused tests and a separate commit. Avoid template-specific
special cases and do not mark cached pixels as semantic support.
