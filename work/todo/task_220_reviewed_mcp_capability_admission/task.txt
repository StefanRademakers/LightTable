Task 220 - Reviewed MCP capability admission and remote proof

Goal
====

Admit completed semantic capability categories to Agent Access and external
MCP through explicit permissions, shared schemas and real remote-to-desktop
evidence. Local command existence alone is not remote approval.

Required work
=============

- Review categories for read/edit/generate/export/overwrite/filesystem/network
  authority and explicit user consent.
- Generate remote tool schemas/discovery from the admitted command contracts.
- Keep withheld commands machine-readable with exact admission blockers.
- Enforce capability availability, revisions, bounded artifacts, rate limits,
  concurrency, cancellation, reconnect and structured errors at the desktop
  boundary.
- Verify dedicated coarse workflow tools still resolve to catalog commands.
- Add real MCP-to-packaged-desktop proofs for each admitted effect class:
  read, immediate edit, gesture commit, atomic batch, async task and artifact.
- Record agent origin/activity without accepting spoofed origin metadata.

Definition of done
==================

- Everything advertised remotely is accepted by the desktop profile and has a
  proven canonical executor.
- Every withheld capability has a reviewed reason; missing/false is not enough.
- Representative scope denial, stale revision, cancellation, reconnect and
  oversized payload cases fail safely.
- The report separates protocol/security proof from creative product quality.

Non-goals
=========

- Automatically exposing every new local command.
- Granting unrestricted desktop, filesystem or network control.
- Treating OAuth/tool enumeration alone as artist capability proof.

Current evidence (2026-08-20)
=============================

- Live gesture sessions are limited to one per document, 4,096 samples and a
  30-second lease renewed only by accepted updates.
- Timeout, document close, service disposal and local Agent Access stop cancel
  transient work through the existing editor finish/cancel boundary.
- Packaged Agent Access interruption/restart proves abandoned gesture cleanup
  and immediate recovery; deployed tunnel reconnect behavior remains open.
- `raster.fill` is explicitly admitted as an immediate edit with bounded scalar
  parameters and no raster payload. Packaged Agent Access plus real external
  MCP-to-desktop execution passed, including decoded rendered-preview evidence.
- `raster.applyGradient` is admitted as one bounded final paint, not a remote
  drag. Packaged and external MCP execution passed with contrasting rendered
  source/result evidence.
- Dodge, Burn and Sponge are admitted only as bounded final semantic strokes;
  the remote route never transports dabs, pixels or live pointer updates.
- Clone and Healing are admitted under the same bound with a document-relative
  sampled-source descriptor. Nested/cross-document runtime IDs, malformed
  source plans and oversized requests fail validation before GPU execution.
- Magic Wand is admitted as a bounded selection recipe. Remote callers provide
  no raster mask or runtime revision; source existence and every option are
  validated before the existing asynchronous GPU owner runs.
- Path Text creation is admitted through the existing `text.create` capability.
  Remote callers reference an existing native contour and bounded layout
  values; no path geometry, pointer stream or editor selection state crosses
  the boundary.
- Actions now awaits accepted export/batch tasks through the same bounded task
  registry exposed to Agent/MCP queries. Artifact publication precedes terminal
  completion, and Stop cancels the canonical document task rather than a UI-only
  placeholder.
