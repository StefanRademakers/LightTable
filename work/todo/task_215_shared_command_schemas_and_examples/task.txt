Task 215 - Shared command schemas and executable examples

Goal
====

Promote the current top-level parameter-property inventory into versioned,
machine-readable input and result contracts consumed by the command service,
Actions and MCP. Add small executable examples that teach both people and
agents how properties work together.

Parent goal
===========

[`architecture/goals/AGENT_NATIVE_CREATIVE_RUNTIME_TARGET.md`](../../../architecture/goals/AGENT_NATIVE_CREATIVE_RUNTIME_TARGET.md)

Depends on
==========

- [`Task 214`](../task_214_complete_action_command_mcp_coverage/task.txt) for
  truthful command ownership and category coverage.

Required work
=============

- Define modular schemas by product category; do not create one huge registry
  file.
- Model required/optional fields, conditional variants, ranges, limits,
  coordinate spaces, stable targets, task results and error results.
- Keep domain validation for rules that cannot be expressed safely in schema,
  but prevent contradictory duplicate validation truth.
- Generate Actions property controls and MCP discovery/input projections from
  the same source.
- Add versioned examples for direct, conditional, ID-bound and async commands.
- Cache compiled validators; schema adoption may not enter pointer-preview hot
  paths or materially slow ordinary UI commands.
- Define migration behavior for recorded/saved Actions when schemas change in
  alpha.

Representative proof
====================

- Layer rename/fill visibility as simple scalar/ID cases.
- Text create/format and vector create/update as conditional nested cases.
- Export as an async artifact-result case.
- Invalid, oversized and contradictory input is rejected consistently through
  local Actions and MCP before mutation.

Definition of done
==================

- Every admitted command has a complete shared input/result contract or an
  explicit machine-readable schema-blocking reason.
- Actions and MCP show the same property names, defaults, limits and examples.
- Runtime validation and advertised schemas cannot silently diverge.
- Generated files pass drift checks and remain split into maintainable modules.
- Representative real command executions pass; schema count alone is not done.

Non-goals
=========

- Free-form arbitrary JSON/state mutation.
- Freezing a public 1.0 API during alpha.
- Building the complete Actions workflow UX in this task.

Current evidence (2026-08-20)
=============================

- Structural layer, selection, affine-transform, committed paint and basic
  Grade commands publish machine-readable parameter properties and examples.
- The 14 basic Grade ranges now have one application-owned map consumed by
  both the real sliders and `grade.setBasic` validation.
- Stable result binding supports nested Grade targets during packaged Action
  replay.
- The semantic text-style contract now explicitly distinguishes synthetic
  bold/italic from font weight/style; UI recording, command validation,
  execution, text query and the dedicated MCP text tool share those meanings.
- Vector Gradient Fill and raster-gradient commands now consume one bounded
  gradient-paint validator, including stop counts, IDs, coordinate space,
  transform bounds and a 64 KiB transport ceiling.
- The brush-stroke schema now documents and validates an optional bounded tone
  operator for Dodge, Burn and Sponge rather than depending on toolbar state.
- The same schema now describes Clone and Healing source anchor, source point,
  sample mode, offset and diffusion. The request document remains authoritative;
  recorded Actions reject a nested runtime document ID.
- Magic Wand has an explicit schema/example for source layer, bounded point,
  combine mode, sample size, tolerance, anti-aliasing, contiguity and layer
  sampling. Runtime document revisions and raster masks are rejected.
- `text.create` now documents point, paragraph and native path modes. Path Text
  carries stable path references plus bounded layout settings, never vector
  geometry or runtime editor objects.
- A modular JSON Schema v1 layer contract now owns input and result shape for
  rename, visibility, fill opacity, blend mode and lock. Generation checks its
  property names against legacy discovery; application tests check the blend
  enum against the real product list.
- The local Commands view generates typed fields/defaults/enums/errors from
  those schemas. A packaged Electron/Playwright flow executed a real rename
  through that form and verified the resulting stable layer state.
- Direct command execution, local atomic batches and external MCP execution/
  batches validate the same schema before mutation or a desktop bridge call.
  Atomic batch results now match direct results for stable downstream bindings.
- MCP discovery separates these `complete` version-1 contracts from commands
  that still expose `legacy-properties-only` metadata.
- A separate layer-structure module adds duplicate, Layer via Copy, delete,
  move and clipping without growing the first schema file. New stable layer IDs,
  copy scope and canonical target lists have explicit result contracts.
- Packaged Commands UI proved the generated move enum by changing real sibling
  order. External MCP proved duplicate/copy stable-ID results, clipping toggles,
  down/up movement and exact deletion results against the desktop bridge.
- A separate Text module now owns all four semantic Text inputs and results.
  Conditional point/paragraph/path creation, paired range offsets, nested font,
  fill/stroke and paragraph variants, safe integer bounds and no-op rejection
  match the application parser rather than only describing top-level names.
- The generator discovers sorted v1 schema modules, detects duplicate command
  IDs and normalizes the legacy optional-property notation for drift checks;
  adding a category no longer requires editing a central schema import list.
- The local Commands editor now recursively renders nested objects, explicit
  optional add/remove groups and union variants. Packaged Electron created and
  queried real editable point text through those controls; no arbitrary command
  JSON field was introduced.
- External MCP discovery reports the Text contracts as complete. Invalid Path
  Text plus private state was rejected without a revision change; real point and
  native Path Text continued to pass the desktop bridge. Text schema evaluation
  remains outside all gesture sample and pointer-preview paths.
- Recorded steps now carry either the complete command-schema version used at
  record time or an explicit `legacy-properties-only` marker. Version-1 Action
  libraries are checked against current input/result schemas and rewritten as
  version 2 only when compatible. Load and playback reject missing, malformed,
  newer or otherwise incompatible complete contracts before any command runs.
- A separate Transform module now owns exact bounded affine `layer.setTransform`
  input/results and the five contextual `transform.applyFixed` operations plus
  their selection/mask/layer/group targets. Generated Actions defaults expose
  the full identity matrix; MCP discovery reports both contracts as complete.
- Packaged Actions and route-equivalence smokes exposed two prior Text contract
  boundary errors that unit/form-only proof had missed: native Type-tool create
  leaked the internal `kind` discriminant and pointer pressure, while observed
  formatting returned a private `changed` flag. UI projection now emits the
  same stable Text parameters/results as Actions and MCP. Observed complete-
  schema results are validated before they can enter a recording.
- Packaged UI/Actions/MCP route equivalence now passes with exact affine replay,
  native Type-tool creation and formatting. External MCP separately proves
  transform discovery, rejects private affine runtime fields without a revision
  change, and executes the real contextual fixed-transform owner.
- A separate Layer Mask module now gives direct `layer.createRaster` a closed
  empty input plus a stable non-null created-layer result, and gives
  `layer.setMask` operation-specific add/remove/enable/link inputs and results.
  Actions derives only relevant defaults; MCP discovery exposes both complete
  contracts and rejects cross-operation mask fields before document mutation.
- A separate Selection module now bounds final geometric shapes, Magic Wand
  sample recipes and conditional Feather state without exposing generated masks
  or pointer samples. Complete result schemas align native UI observation with
  direct Actions/MCP execution; MCP rejects private point pressure state.
- A separate Basic Grade module now owns the document/layer target union, all
  14 application-owned numeric ranges, non-empty partial patches and canonical
  changed/no-op results. A drift test compares schema ranges to the real slider
  map; MCP rejects private curve payloads before document mutation.
- A separate Merge/Flatten module now constrains destructive sibling merges,
  group targets and option-free image flattening, including stable output-layer
  results. Duplicate merge IDs and expanded image options fail before execution.
- A separate finalization module now exposes explicit raster/mask inversion and
  retained-ID Text-to-Shape/Text-to-Raster results. Output types are constants,
  while live text editing and GPU payloads remain outside the command boundary.
- A separate raster-paint module now describes solid Fill and complete final
  Gradient paint, including bounded stops, transforms, coordinate spaces and
  blend modes. Actions uses the shared examples for valid nested initial state;
  MCP rejects pointer samples before the GPU/history owner.
- A composable local `$defs`/`$ref` schema boundary now keeps rich contracts
  reusable without duplicating nested structures. The Vector module uses it for
  primitives, paths, live geometry, solid/gradient paint and complete strokes
  across create/update/remove, with stable layer/element results.
- A separate Artifact module now owns `file.openArtifact` and
  `layer.placeArtifact`: bounded registry IDs, an optional safe layer name and
  finite placement coordinates produce stable document/layer IDs and decoded
  dimensions. Unknown pointer/UI state and raw bytes are rejected. Reachable
  `$defs` are pruned independently for each generated command contract.
- The external URL-import MCP tool proves both routing variants: with a target
  document it places a layer; without one it opens a document. Real packaged
  desktop smoke additionally uploads and decodes a valid PNG, executes placement
  through external MCP and opens it through the authenticated bridge.
- A separate Layer Effects module now owns stack enable/update and effect add,
  update, enable, move and remove contracts. Its closed nested definitions cover
  Drop/Inner Shadow, Outer/Inner Glow, Bevel & Emboss, Color/Gradient/Pattern
  Overlay, Satin and Stroke without accepting private editor state or settings
  from a different effect kind. Examples seed Actions and MCP from the same
  source. Contextual kind validation remains at the application boundary where
  plain JSON Schema cannot relate an existing effect ID back to its canonical
  kind.
- Packaged UI proof exercised 121 Blur input events while recording exactly one
  semantic update; undo and Actions playback reproduced the canonical value.
  The external MCP smoke executes the complete Layer Style lifecycle and checks
  that invalid mixed-kind settings leave the document revision unchanged.
- View zoom, Undo/Redo, task cancellation and native/PNG/PSD export now publish
  complete shared version-1 contracts. Conditional custom zoom is bounded,
  control commands reject extra state, and exports return only typed opaque
  artifact metadata with command-specific kinds and bounded PSD findings.
  The external MCP smoke rejects host paths/Base64/private options, executes the
  packaged viewport owner and produces real native/PNG/PSD artifacts through the
  existing task and renderer owners.

Still required for completion
=============================

- formal versioned input and result schemas for every admitted command;
- generated Actions property editors for every remaining parameterized command;
- explicit blocking reasons for every command without a complete schema.
