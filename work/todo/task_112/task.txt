# Task 112 — release-candidate rehearsal and go/no-go report (P4)

Priority: P4. Depends on Tasks 107–111 and all unresolved P0/P1 defects.
Expected effort: 8–12 focused hours.

## Objective

Produce one reproducible release candidate and decide from evidence whether it
is ready for a paid public release, a bounded technical preview or no release.

## Required work

- Cut the candidate from a clean, identified commit with deterministic version,
  changelog, migration range, compatibility table and deferred-feature list.
- Run the full test ladder: boundaries, unit/integration, production builds,
  packaged desktop smokes, Photoshop parity corpora, persistence/recovery,
  accessibility, security, hardware matrix and multi-hour soak.
- Repeat the owner acceptance workflow on the exact packaged candidate.
- Install and update through the staging distribution path, exercise rollback,
  restore a crashed session and export/reopen representative native/PSD/PDF
  results.
- Audit that cached/raster fallbacks are disclosed, source semantics are
  retained where promised and no unsupported operation silently destroys data.
- Freeze results and raw measurements; do not rerun selectively to hide a
  failure or lower a ratchet without an architectural explanation.

## UI exposure

The candidate exposes final version/channel, compatibility, recovery, privacy,
diagnostics and support information through existing product surfaces. Remove
or gate development-only controls and verbose telemetry.

## Verification and completion

- Publish a signed go/no-go report against every commercial release gate in the
  product assessment, including evidence links and named unresolved risks.
- A paid-release decision requires zero supported-path data-loss/crash blockers,
  owner sign-off, declared hardware passes and truthful compatibility claims.
- If a gate fails, label the build technical preview or no-release and create
  focused follow-up defects; do not mark this task done as a paid RC.
- Verify clean worktree/reproducible artifacts, commit final documentation and
  move to done only at the declared outcome.
