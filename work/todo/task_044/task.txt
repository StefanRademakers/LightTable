# Task 044 - PSD/PDF open, save and editable overlay audit

Status: active

## Verified current behavior

- [x] PSD/PSB and PDF are accepted by the shared File > Open route.
- [x] File > Save LightTable stores the editable canonical document rather than
  pretending to round-trip the source interchange format.
- [x] File > PDF Export Preflight exposes the currently supported flattened and
  bounded hybrid PDF deliverables.
- [x] A raster layer created above an imported PDF is active, editable and
  paintable. Packaged Electron smoke on `D:\FormulierPersoneel.pdf` creates a
  raster layer, paints a red GPU brush stroke, publishes a new pixel revision
  and refreshes its layer thumbnail.

## Dependency and licensing rule

Permissively licensed libraries may be integrated after license inventory and
notice checks. Other open-source implementations may be used only as research
for an independently designed implementation. Any shipped third-party code or
asset must be recorded in the generated inventory and surfaced through the
app's existing third-party notices UI.
