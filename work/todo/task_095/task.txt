# Task 095 — large-document open and direct-interaction performance (P1)

Priority: P1. Depends on Task 089. Expected effort: 8–14 focused hours.

## Objective

Reduce measured PSD first-use and ordinary canvas interaction latency without
quality loss, extra hot-path readbacks or architectural complexity.

## Required work

- Profile EHS-396 and the ten-template corpus by I/O, parse, composite preview,
  semantic hydration, upload, first useful frame and deferred work.
- Profile caret, text hit-testing, transform settle, layer selection, pan/zoom,
  style controls and paint with event-to-submit/GPU/final metrics.
- Prioritize retained-composite-first, bounded newest-work hydration,
  backpressure and dirty-region/subtree recomposition based on evidence.
- Test every cache/allocation proposal A/B for warm speed, residency, visual
  equality, invalidation and developer complexity; reject unproven systems.
- Keep optional fonts/effects/codecs lazy and inactive documents asleep.

## UI exposure

Use existing progress/status phases when an operation is genuinely pending.
Never mask slowness with fake completion or persistent debug messages.

## Verification and completion

- Record before/after medians/p95, GPU bytes, submissions and CPU→GPU bytes.
- Settled pixel differences must be zero or within a declared parity threshold.
- Test ordinary PNG/JPEG fast path and modest-hardware settings for regressions.
- Run render-engine, text/vector, canvas, corpus and quality gates.
- Update performance risk register, commit each accepted optimization and move.
