Task 261 - Intermittent packaged React update-depth error
========================================================

Goal
====

Reproduce and remove the intermittent minified React error 185 observed during
the packaged UI/Actions/MCP route-equivalence workflow, or prove and document a
specific benign external cause. A completed visual/state comparison is not
enough when the page emitted a runtime error.

Evidence and scope
==================

- On 2026-08-20 two consecutive runs completed all route work but failed the
  final page-error gate with React error 185 (maximum update depth).
- The next two isolated runs passed without page errors.
- Error collection now retains `error.stack` where Electron provides it.
- Do not weaken or retry away the page-error gate.

Checklist
=========

- [ ] Capture the first failing interaction and usable component/runtime stack.
- [ ] Determine whether Actions panel, document activation, task publication or
      another external-store subscription forms the update loop.
- [ ] Add a deterministic regression or bounded repeated-run harness.
- [ ] Fix the owner without suppressing React errors.
- [ ] Re-run packaged UI/Actions/MCP equivalence and related full gates.

Non-goals
=========

- Treating a later green run as proof that the error cannot recur.
- Filtering error 185 from test output.
