Task 217 - UI, Actions and MCP equivalence harness

Goal
====

Prove that representative artist operations invoked through normal UI,
recorded Actions and the real MCP-to-desktop path reach the same semantic owner
and produce equivalent editable state, history and rendered output.

First artist workflow
=====================

On fresh equivalent documents:

1. create a vector shape;
2. set fill and stroke;
3. transform and rename its layer;
4. create and format editable text;
5. use a result binding rather than a recorded generated ID;
6. undo/redo a logical edit;
7. render and export a preview.

Required comparisons
====================

- normalized canonical document/scene state;
- stable relationships while ignoring legitimately regenerated IDs;
- history depth, labels and undo/redo outcome;
- capability/revision and structured result semantics;
- rendered pixels using a declared visual tolerance and difference artifact;
- rejection behavior for invalid parameters and stale revisions.

Definition of done
==================

- The three routes pass through the real application command owners.
- The complete workflow passes in packaged desktop, including real MCP bridge.
- Failures show the exact divergent state/history/render stage.
- No single aggregate score is used as proof; representative images and
  editable structure are both reviewed.

Non-goals
=========

- Claiming whole-application equivalence from one workflow.
- Reimplementing the UI path in a synthetic test-only adapter.

Current evidence (2026-08-20)
=============================

- A dedicated packaged route-equivalence smoke now uses one real UI recording
  as the authoritative recipe for a rectangle with explicit fill/stroke,
  transform, rename, editable point text and faux-bold formatting. Actions
  replays that exact recording in a fresh document and the authenticated
  external MCP TLS/device tunnel resolves the same recorded result bindings
  and executes the same six semantic commands in a third document, including
  `file.exportPng`.
- The normal File > Export PNG menu route now calls that same semantic export
  owner instead of rendering through its previous parallel UI path. The
  command task is the sole render/artifact owner; the UI only resolves its
  bounded artifact and dispatches the resulting File to the desktop host.
  Avoiding a nested UI `export` task is intentional because both would share
  one per-document task registry and cancel each other.
- Packaged evidence records the actual menu click, waits for the recorder's
  completed PNG artifact, replays it through Actions (whose export gate
  requires a completed artifact), and inspects the external MCP task through
  `lighttable_task`. UI and MCP artifacts are both non-empty `png-export`
  results of 11,140 bytes in the current fixture. The host-delivered UI PNG is
  pixel-exact to the canonical revision-bound preview; all four generated PNGs
  also have the same SHA-256 in the current run.
- All three routes now expose matching bounded Undo/Redo labels, depths and
  state IDs. Undo/Redo restores the same editable state while advancing the
  canonical revision from 5 to 7 on every route.
- That harness found and fixed two real publication gaps: local keyboard
  Undo/Redo bypassed the semantic command owner, and already-committed UI
  gestures were recorded without advancing the public document revision.
  Semantic commands suppress their own nested UI observations, so replay and
  MCP still publish exactly one revision per logical edit.
- Normalized layer, vector and text state is identical across UI, Actions and
  external MCP after generated document/layer/element IDs are rebound. The
  comparison retains relationships, geometry, transforms, fill/stroke, font,
  text runs and history while excluding gesture-preview-only internal
  revision counters.
- Revision-bound 640x480 GPU previews are pixel-exact in this bounded workflow:
  UI vs Actions and UI vs MCP both report zero per-channel MAE/RMSE, zero p95
  and maximum delta, and zero changed pixels. Side-by-side and amplified
  difference PNGs are retained under `tmp/route-equivalence-smoke/` and were
  visually reviewed. This is not a whole-application parity claim.
- The document query now exposes only the bounded next `undoLabel` and
  `redoLabel`, not an unbounded history stack, so agents can verify the logical
  operation before navigating history.

- Layer duplicate/delete/move/blend/clipping/visibility/locks have a real
  UI-origin, Actions and MCP canonical-state/history equivalence harness.
- Geometric selection and single-layer affine transform use the same stable-ID
  commands from recorded UI operations and remote execution.
- Selection All, Invert and Clear have equivalent UI-origin, Actions and MCP
  state/history proof and remain selection-only (document revision stays 0).
- Basic Grade has UI-origin, Actions and authenticated MCP equivalence for a
  multi-property document patch; packaged Actions separately proves the real
  Exposure slider and stable nested layer binding. Packaged Agent Access now
  also sets and reads back the canonical 14-control Grade projection while
  proving the read leaves revision/history unchanged.
- A packaged Agent Access flow creates vector content, applies a selection,
  transforms and blends a layer, then queries canonical state.
- A packaged Actions flow records UI transform, selection and Brush work,
  undoes it and replays it with stable result binding.
- Packaged Actions records UI point-text creation plus faux-bold formatting,
  binds `text.format` to the new layer, undoes/replays both and confirms the
  result remains editable flow text. Packaged Agent Access separately creates,
  formats and queries native text including faux italic and underline.
- Reveal-all mask lifecycle/state has canonical UI/Actions/MCP equivalence.
  The packaged Actions path also bakes the existing selection into a mask,
  replays its disabled state and verifies canonical mask data. Packaged Agent
  Access targets a non-active layer and leaves artist focus unchanged.
- Native shape creation is shared through `vector.create`: unit round-trips
  cover Rectangle, Ellipse, Triangle and Line properties, while packaged
  Actions proves a real Rectangle gesture, undo and native editable replay.
- Native Pen paths share `vector.create`/`vector.update`: packaged Actions
  records a real three-anchor gesture, binds its generated layer, undoes and
  replays editable path geometry. Packaged Agent Access creates a three-anchor
  path in an existing vector layer and reads the native anchors/style back.
- Packaged Actions records and replays a real Direct Selection path edit using
  bindings to the generated Pen layer/element. Packaged Agent Access executes
  the same full-path update and queries the changed anchor position back.
- Packaged Actions replays a native Gradient Fill with its special layer role
  and editable axis. Packaged Agent Access creates, edits and queries the same
  role, layer presentation and gradient transform through shared contracts.
- Packaged Actions records, binds, undoes and replays Push and held Twirl Warp
  recipes. Packaged Agent Access executes the same `warp.applyStroke` owner and
  reads its bounded layer-source recipe through `warp.query`; the external MCP
  smoke also executes and queries this recipe through the real desktop bridge.
  Rendered-output equivalence remains intentionally unclaimed.
- Packaged Actions records and replays a real toolbar Fill with stable target
  binding. Packaged Agent Access and external MCP execute the same explicit
  raster operation; the MCP route verifies an actual decoded preview pixel.
- Raster Gradient has the same packaged UI/Actions/Agent/MCP route. External
  MCP preview evidence distinguishes its blue-to-cyan result from a red source
  fill, while the editable final paint is retained in the Action parameters.
- Dodge and Sponge now have representative packaged UI/Actions, Agent Access
  and external MCP execution through the same GPU paint-session owner.
- Clone now has packaged UI recording, undo and Actions replay; direct Agent
  Access executes Clone and the external MCP bridge executes Healing through
  the same sampled-brush renderer owner. This proves route equivalence, not
  Photoshop visual parity.
- The apparent active-layer reversion was isolated to stale smoke coordinates
  landing outside the viewport. A dedicated packaged Fill/Gradient/Brush
  selection-stability smoke passes; no unproven product-state fix was added.
- Packaged UI records and replays a real Magic Wand result after GPU completion.
  Agent Access and external MCP execute the same asynchronous owner using only
  the bounded sampling recipe.
- Packaged UI records a real selected-contour Path Text creation as
  `text.create`, undoes and replays it with stable result bindings. Agent Access
  and the external MCP bridge create and query the same editable native path
  references and layout settings.
- A packaged restart harness now proves a saved create+rename Action loads into
  a fresh document session, retargets its document ID, preserves its generated
  layer binding and does not record its own playback.
- Packaged Actions now records and replays an asynchronous native export through
  the same document-task/artifact owners. Unit equivalence carries its newly
  generated artifact ID into a following bound command; failure and Stop do not
  continue later steps.
- The external MCP workflow now renders bounded artifacts explicitly tied to
  revisions N and N+1 around its semantic edits. The preview path uses the GPU
  thumbnail owner and retains per-artifact context; it is not an aggregate score.
- That workflow now also captures a publication cursor before editing and
  requires the final document revision plus history state to appear before the
  N+1 preview is accepted.
- The packaged secure MCP design workflow now requests its bounded preview at
  an exact queried revision and exports final PNG, native and PSD artifacts
  only after the same opacity edit plus undo/redo has reached the final render
  boundary. Previously its PNG artifact was exported before that final edit.
- Its Photoshop roundtrip no longer relies on `RMSE < 20` plus a side-by-side.
  The reproducible report retains per-channel MAE/RMSE/maxima, pixel-delta
  percentiles, changed-pixel ratios, source dimensions, explicit workflow
  tolerances, a side-by-side and a 4x absolute-difference image. Aspect-ratio
  mismatches fail instead of being stretched into a score.
- Visual review of that evidence found that editable layer kinds and text
  geometry survive, but the Photoshop roundtrip still has a clear global
  gradient shift and a different title shadow. The automated interchange
  guardrail passes (RMSE 9.79, MAE 6.27, p95 pixel delta 26), but rendered
  equivalence is explicitly not claimed from those numbers.
