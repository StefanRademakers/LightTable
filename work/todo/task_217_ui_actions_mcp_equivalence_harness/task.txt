Task 217 - UI, Actions and MCP equivalence harness

Goal
====

Prove that representative artist operations invoked through normal UI,
recorded Actions and the real MCP-to-desktop path reach the same semantic owner
and produce equivalent editable state, history and rendered output.

===========

First artist workflow
=====================

On fresh equivalent documents:

1. create a vector shape;
2. set fill and stroke;
3. transform and rename its layer;
4. create and format editable text;
5. use a result binding rather than a recorded generated ID;
6. undo/redo a logical edit;
7. render and export a preview.

Required comparisons
====================

- normalized canonical document/scene state;
- stable relationships while ignoring legitimately regenerated IDs;
- history depth, labels and undo/redo outcome;
- capability/revision and structured result semantics;
- rendered pixels using a declared visual tolerance and difference artifact;
- rejection behavior for invalid parameters and stale revisions.

Definition of done
==================

- The three routes pass through the real application command owners.
- The complete workflow passes in packaged desktop, including real MCP bridge.
- Failures show the exact divergent state/history/render stage.
- No single aggregate score is used as proof; representative images and
  editable structure are both reviewed.

Non-goals
=========

- Claiming whole-application equivalence from one workflow.
- Reimplementing the UI path in a synthetic test-only adapter.

Current evidence (2026-08-20)
=============================

- Layer duplicate/delete/move/blend/clipping/visibility/locks have a real
  UI-origin, Actions and MCP canonical-state/history equivalence harness.
- Geometric selection and single-layer affine transform use the same stable-ID
  commands from recorded UI operations and remote execution.
- Selection All, Invert and Clear have equivalent UI-origin, Actions and MCP
  state/history proof and remain selection-only (document revision stays 0).
- Basic Grade has UI-origin, Actions and authenticated MCP equivalence for a
  multi-property document patch; packaged Actions separately proves the real
  Exposure slider and stable nested layer binding. Packaged Agent Access now
  also sets and reads back the canonical 14-control Grade projection while
  proving the read leaves revision/history unchanged.
- A packaged Agent Access flow creates vector content, applies a selection,
  transforms and blends a layer, then queries canonical state.
- A packaged Actions flow records UI transform, selection and Brush work,
  undoes it and replays it with stable result binding.
- Packaged Actions records UI point-text creation plus faux-bold formatting,
  binds `text.format` to the new layer, undoes/replays both and confirms the
  result remains editable flow text. Packaged Agent Access separately creates,
  formats and queries native text including faux italic and underline.
- Reveal-all mask lifecycle/state has canonical UI/Actions/MCP equivalence.
  The packaged Actions path also bakes the existing selection into a mask,
  replays its disabled state and verifies canonical mask data. Packaged Agent
  Access targets a non-active layer and leaves artist focus unchanged.
- Native shape creation is shared through `vector.create`: unit round-trips
  cover Rectangle, Ellipse, Triangle and Line properties, while packaged
  Actions proves a real Rectangle gesture, undo and native editable replay.
- Native Pen paths share `vector.create`/`vector.update`: packaged Actions
  records a real three-anchor gesture, binds its generated layer, undoes and
  replays editable path geometry. Packaged Agent Access creates a three-anchor
  path in an existing vector layer and reads the native anchors/style back.

Still required for completion
=============================

- high-frequency typing/IME recording and text failure equivalence across all
  three routes;
- revision-bound rendered preview/export comparison with declared per-image
  tolerances and retained difference artifacts;
- the complete workflow through the external MCP bridge, not only the packaged
  in-app Agent Access route;
- equivalent stale-revision and invalid-parameter failure evidence at every
  real route boundary.
- rendered comparison for native shapes and paths, plus external MCP-tunnel
  proof; current Pen evidence reaches the packaged Agent Access boundary.
